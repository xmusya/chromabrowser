# ChromaBrowser

**ChromaBrowser** — веб-браузер для терминала с картинками. Он открывает
настоящие сайты, рисует HTML (заголовки, списки, таблицы, цитаты, код, формы)
и показывает изображения прямо в текстовом окне с помощью цветных
полублоков `▀`.

```
▌ Добро пожаловать
──────────────────────────────────────────────────────────────
  • текст, ссылки, таблицы и картинки — всё в терминале
  • управление как в vim: j/k, g/G, /, f, q
```

## Возможности

- Загрузка страниц по HTTP/HTTPS, локальных файлов и `file://`-ссылок.
- Разбор HTML через BeautifulSoup; аккуратная вёрстка под ширину терминала.
- **Картинки в терминале**: PNG, JPEG, GIF, WebP, BMP и другие форматы,
  которые понимает Pillow. Картинка переводится в полублоки `▀` с
  раздельными цветами верха и низа — получается вдвое больше «пикселей» по
  вертикали.
- Truecolor (24 бита), автоматический откат на палитру xterm-256.
- Ссылки: подписи-подсказки (`f`), переход по Tab/Enter, клик мышью.
- Поиск по странице (`/`, `n`, `N`) с подсветкой.
- История, закладки и панели со списками.
- Масштаб картинок (`+`/`-`/`0`), включение и выключение картинок (`i`).
- Просмотр исходного HTML (`v`), сохранение страницы (`Ctrl+S`),
  скачивание ссылок (`d`), копирование URL через OSC 52 (`y`).
- Никакого JavaScript, рекламы и телеметрии. Куки сохраняются локально.

## Установка

Нужен Python 3.10+ и модуль `venv`. В Debian/Ubuntu:

```sh
sudo apt install python3 python3-venv python3-pip
```

Затем в каталоге проекта:

```sh
./install.sh
```

Скрипт создаст `.venv`, установит зависимости (`requests`, `pillow`,
`beautifulsoup4`) и положит ссылку `~/.local/bin/chroma`. Убедитесь, что
`~/.local/bin` есть в `PATH`.

Ручная установка:

```sh
python3 -m venv .venv
.venv/bin/pip install -e .
./bin/chroma https://example.com
```

Можно запускать и без установки, из каталога проекта:

```sh
.venv/bin/python -m chromabrowser https://example.com
```

## Запуск

```sh
chroma                      # стартовая страница
chroma example.com          # сайт (https:// добавится сам)
chroma https://example.com
chroma ./page.html          # локальный файл
chroma "терминальный браузер"   # поиск в интернете
```

Полезные ключи:

| Ключ | Что делает |
| --- | --- |
| `--dump` | отрисовать страницу в stdout и выйти (без интерактива) |
| `--width N` | ширина для `--dump` |
| `--color auto\|truecolor\|256\|never` | режим цвета |
| `--no-images` | не показывать картинки |
| `--home URL` | другая стартовая страница |
| `--version` | версия |

Пример:

```sh
chroma --dump --width 100 --no-images https://example.com
```

## Управление

| Клавиши | Действие |
| --- | --- |
| `o` | открыть адрес / поиск |
| `Ctrl+L` | редактировать текущий URL |
| `f` | показать метки ссылок, затем нажать метку |
| `Tab` / `Shift+Tab` | перейти к следующей / предыдущей ссылке |
| `Enter` | открыть ссылку в фокусе |
| `j` / `k`, `↓` / `↑` | прокрутка на строку |
| `Space`, `PgDn`, `Ctrl+F` | на экран вниз |
| `PgUp`, `Ctrl+B` | на экран вверх |
| `Ctrl+D` / `Ctrl+U` | пол-экрана вниз / вверх |
| `g`, `Home` | в начало |
| `G`, `End` | в конец |
| `Backspace`, `Alt+←` | назад |
| `Alt+→` | вперёд |
| `r`, `Ctrl+R` | перезагрузить |
| `/` | поиск по странице |
| `n` / `N` | следующее / предыдущее совпадение |
| `Esc` | закрыть окно/поиск, отменить загрузку |
| `b` | закладки |
| `B` | добавить/удалить текущую страницу в закладки |
| `H`, `Ctrl+H` | история |
| `d` | скачать ссылку (по меткам) |
| `i` | включить/выключить картинки |
| `+` / `-` / `0` | увеличить / уменьшить / сбросить масштаб картинок |
| `v` | исходный HTML |
| `y` | скопировать URL (OSC 52) |
| `Ctrl+S` | сохранить страницу |
| `q`, `Ctrl+C` | выход |

Мышь: колесо — прокрутка, левый клик — переход по ссылке.

## Настройки и данные

Конфигурация: `~/.config/chromabrowser/config.json` — создаётся
автоматически. Основные поля:

```json
{
  "homepage": "about:start",
  "search_engine": "https://lite.duckduckgo.com/lite/?q={query}",
  "images": true,
  "zoom": 1.0,
  "max_image_width": 96,
  "color": "auto",
  "download_dir": "~/Downloads",
  "page_timeout": 25.0,
  "image_timeout": 8.0,
  "max_page_mb": 25.0
}
```

- История и закладки: `~/.local/share/chromabrowser/`
- Куки: `~/.local/share/chromabrowser/cookies.txt`
- Кэш картинок: `~/.cache/chromabrowser/images/`

## Ограничения

- **Нет JavaScript.** Страницы, которые целиком рисуются скриптами, будут
  пустыми или почти пустыми.
- CSS поддерживается только частично: цвета текста и фона, жирность,
  курсив, подчёркивание, зачёркивание. Нет flex/grid, позиционирования и
  медиазапросов — вёрстка всегда линейная.
- Картинки рисуются полублоками: это работает в любом truecolor-терминале
  (и с откатом на 256 цветов), но не является протоколом Sixel/Kitty.
  Точность цвета и геометрия зависят от шрифта терминала.
- Нужен терминал с UTF-8. Минимальный удобный размер — примерно 80×24;
  при меньшей ширине часть элементов (логотип, подсказки) упрощается.
- SVG, видео и аудио не отображаются — вместо них выводится пометка.
- `rowspan`/`colspan` в таблицах не поддерживаются, сложные таблицы
  упрощаются.
- Сложные сайты (почта, соцсети, карты) работать не будут — проект рассчитан
  на чтение текста и картинок.

## Тесты

```sh
.venv/bin/pip install -e ".[dev]"
.venv/bin/python -m pytest tests -q
```

Тесты покрывают перенос текста, canvas/ANSI, декодирование клавиш и мыши,
HTML-вёрстку, картинки, хранилище, сеть, CLI и интерактивный режим
(через настоящий pty + pyte).
